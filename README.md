# Stockroom — каталог товаров (лабораторная работа № 1)

Учебное SPA-приложение на **React + TypeScript** для варианта № 2 — Products.

## Возможности

- просмотр каталога товаров в виде карточек;
- добавление, редактирование и удаление товаров;
- поиск по названию, бренду, категории и описанию;
- фильтрация по категориям;
- сортировка по цене, остатку и названию;
- отображение остатков, скидок, рейтинга и статуса наличия;
- сохранение изменений в `localStorage` браузера;
- адаптивная вёрстка для мобильных и настольных экранов.

## Технологии

- React 18 и TypeScript;
- Vite;
- React Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`);
- Lucide React для иконок;
- CSS без дополнительной UI-библиотеки.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

## Данные и API

Структура `Product` ориентирована на поля DummyJSON `/products`: `id`, `title`, `description`, `category`, `price`, `discountPercentage`, `rating`, `stock`, `brand`, `thumbnail`. Для демонстрационных карточек используется дополнительное поле `imageKey` с локальным ключом иллюстрации; URL-адрес `thumbnail` оставлен необязательным для будущей интеграции. Согласно условию лабораторной, запросы к DummyJSON не выполняются: демонстрационные данные хранятся в проекте, а пользовательские изменения — в `localStorage`.

## Проверка основных сценариев

1. Добавить товар через кнопку «Добавить товар» и проверить появление новой карточки.
2. Изменить цену или остаток существующего товара и сохранить изменения.
3. Удалить товар через кнопку корзины и подтвердить действие.
4. Ввести часть названия в поиск и выбрать категорию в фильтре.
5. Изменить сортировку и перезагрузить страницу: данные каталога должны сохраниться в браузере.
